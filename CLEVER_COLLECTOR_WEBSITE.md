## Project Overview

**Purpose:** Public-facing marketing landing page for the CleverCollector app.
**Canonical URL:** https://www.clevercollector.com (use `www` consistently across DNS, metadataBase, and OG tags)
**Domain:** CleverCollector.com (registered via GoDaddy)
**Goal:** Inform visitors, establish brand presence, and drive App Store downloads.
**Scope (v1):** Single-page informational site. No e-commerce. No authentication.

## Section-by-Section Spec

### 1. Navbar (`Navbar.tsx`)
- Always sticky with `backdrop-blur` (dark on all scroll positions in v1)
- Left: Text wordmark **CLEVERCOLLECTOR** (Cinzel Black) — replace with `logo-white.png` when asset is ready
- Right: Gold CTA button — **"Download Free"** → anchors to `#download`
- Nav links: Screens · Verticals · Features · Download Free

### 2. Hero (`Hero.tsx`)
- Full-bleed navy-to-black gradient background
- Cinzel Black headline: **"The Collector's Platform"**
- Subheadline: *"Curated content. Collector community. Your collection — all in one place."*
- Two buttons:
  - Primary (gold): **"Download on the App Store"** → App Store link (currently `#download` — update to live App Store URL when available)
  - Secondary (outlined): **"See What's Inside"** → scrolls to `#features`
- Hero graphic: `wheel-mark.svg` or app mockup image (right side on desktop, below text on mobile)

### 3. App screenshots (`AppScreensSection.tsx`)
- Section id: `screens`
- Placeholder grid for three phone screenshots; images load from `public/assets/screens/` (`screen-1.png`, `screen-2.png`, `screen-3.png`). If a file is missing, a dashed placeholder shows the expected filename and path.
- Client component using `next/image` with `onError` fallback.

### 4. Verticals Grid (`VerticalsSection.tsx`)
- Section headline: **"One Platform. Every Passion."**
- Section subheadline: *"Start with what you love. Discover what's next."*
- 6-tile icon grid (3×2 desktop, 2×3 mobile)
